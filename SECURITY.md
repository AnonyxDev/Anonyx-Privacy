# Security

This project has not received an independent security audit. Do not put credentials or private user data into public issues, pull requests, test fixtures, or public environment variables.

For a sensitive vulnerability, use GitHub's private vulnerability reporting if the repository owner has enabled it. Otherwise request a private reporting channel from the maintainer without publishing exploit details. No security contact address is currently configured in the source.

Reports should describe the affected version, impact, minimal reproduction, and proposed mitigation. Request approval, cross-origin message validation, wallet switching, and context persistence are security-sensitive boundaries.
